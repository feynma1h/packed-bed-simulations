# Sample data

One representative settled bed, to document the data formats the pipeline passes
around. (The full slice-image stacks for every bed are intermediate outputs and
are regenerated by the pipeline rather than stored here.)

### `sample-sphere-bed/`

| File | Format |
|------|--------|
| `particle-locations.csv` | One row per particle: `x, y, z` centre coordinates of the settled packing. Exported from Blender ([`03_export_particle_transforms.py`](../code/blender/03_export_particle_transforms.py)); the full export also carries `rot_x, rot_y, rot_z`. Consumed by the Ansys SpaceClaim rebuild and the MATLAB projectors. |
| `porosity-data.csv` | Radial porosity table produced by [`avgRadialPorosity.m`](../code/matlab/avgRadialPorosity.m). Row 1 is the dimensionless wall distance `(R−r)/dp`; each subsequent row is one slice `z=###`, giving porosity vs. radius. |
